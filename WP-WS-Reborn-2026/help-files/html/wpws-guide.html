Overview

WP WS Reborn 2026 fetches content from external URLs and displays it in posts, pages, or themes. You provide a URL and a query (CSS selector, XPath, or regex) to extract the parts you need. You can also strip ad blocks from the result using remove_query (e.g. remove_query=".ads" on article content). Most arguments are optional – when you use a query, only url and query are required.

Basic usage

Shortcode (posts, pages, widgets):

[wpws url="https://example.com" query="div.content"]

Template tag (PHP in themes):

<?php echo wpws_get_content('https://example.com', 'div.content'); ?>

With optional arguments as array:

<?php echo wpws_get_content('https://example.com', 'div.content', array('output' => 'text', 'cache' => 60)); ?>

Query types

There are four ways to select content. The default is a CSS selector.

CSS selector (default)

Use query_type="cssselector" or omit it. Examples:

  • div.content – divs with class content
  • #header – element with id header
  • .sidebar – elements with class sidebar
  • ul li – list items inside ul
  • article h2.title – h2 with class title inside article

XPath

Use query_type="xpath". Handy for XML/RSS. Examples:

  • //div[@class='content']
  • //item/title – RSS item titles
  • //channel/item/title – feed item titles

Regex

Use query_type="regex". Example:

[wpws url="https://example.com" query="/<h2>(.*?)<\/h2>/" query_type="regex"]

JSONPath (for JSON APIs)

Use query_type="jsonpath" when the source returns JSON (REST APIs, etc.). A simplified dot-notation path is supported: named keys, numeric indices (negative allowed), and the * wildcard. A leading $. or $ is optional.

  • $.title – the title field of an object
  • $.0.name – name of the first array element ($.-1.name = last)
  • $.items.*.id – the id of every element under items
  • $ (or empty) – the whole document as a JSON string
[wpws url="https://jsonplaceholder.typicode.com/users" query="$.*.email" query_type="jsonpath" glue=", "]
Each match is returned as a string; objects/arrays are JSON-encoded. Combine with glue, eq, gt, lt just like the other query types.

Request arguments

  • url – Required. Full URL to scrape. Supports dynamic placeholders.
  • cache – How long to store the fetched page before requesting it again, in minutes. Default: 60. Use a higher value (e.g. 360, 1440) for rarely changing content to reduce external requests; use a lower value (e.g. 5, 15) for frequently updated content. Set to 0 to disable caching for that request.
  • timeout – Request timeout in seconds. Default: 10 (minimum enforced: 5).
  • useragent – Custom User-Agent header. Default: latest Chrome (desktop), e.g. Chrome/131.0.0.0.
  • headers – Extra POST body data as query string (switches request to POST), e.g. id=1&key=val.
  • urldecode – 1 or 0. Use 1 for url-encoded URLs (shortcode only). Default: 1.
  • querydecode – 1 or 0. Use 1 for url-encoded query (shortcode only). Default: 0.

See also: authentication, mobile emulation, and AJAX / background refresh arguments.

How caching works: The plugin stores each URL’s response in WordPress (Transients API). For the duration you set with cache, the same URL is not fetched again from the remote site – the stored copy is used instead. This speeds up your pages and reduces load on the target site. For high traffic or many shortcodes, using a cache plugin (object cache / persistent cache) is strongly recommended for better performance.

Response / output arguments

  • output – html (default) or text. The text option strips all HTML tags.
  • glue – String used to join multiple results. Default: a newline.
  • debug – 1 or 0. When set to 1, adds a debug HTML comment. Default: 0.
  • on_error – error_show, error_hide, or any string to display on failure. Default: error_show. See on_error.

Filters: eq, gt, lt

Limit which matched elements are returned. Index is 0-based.

  • eq – Single element: first, last, or number (e.g. eq="3").
  • lt – Elements with index less than N (first N elements). E.g. lt="10" → indices 0–9.
  • gt – Elements with index greater than N (skip first N+1). E.g. gt="2" → from index 3 onward.

Combining gt and lt returns a range: gt="2" lt="8" returns indices 3, 4, 5, 6, 7.

Example – first 10 headings as text, separated by line breaks: 
[wpws url="https://www.w3schools.com/tags/tag_hn.asp" query="h2" output="text" lt="10" glue="<br>"]

Fetches the first 10 <h2> headings from the W3Schools HTML heading tags page.

remove_query & replace_query

remove_query – Removes nodes matching the given query from the result. Typical use: strip ad blocks from an article (e.g. remove_query=".ads" or .advertisement). Use remove_query_type (cssselector, xpath, regex) if not CSS.

Example – article content without ad blocks: 
[wpws url="https://www.w3schools.com/html/html_intro.asp" query="#main" remove_query=".w3-sidebar"]

Fetches the main content from the W3Schools HTML intro page and removes the sidebar. To strip ad blocks on other sites, use query="article" (or the main content selector) and remove_query=".ads" or remove_query=".advertisement" – the exact class depends on the target site.

replace_query / replace_with – Replaces matched content. replace_with is the replacement string; omit to remove.

[wpws url="https://example.com" query=".content" replace_query=".old" replace_with="<span>New</span>"]

basehref & a_target

  • basehref – Converts relative links to absolute. Use 1 (source URL as base), 0 (no change), or a full URL.
  • a_target – Sets target on all <a> links. Common: _blank for new tab.
Example – table from external site, links in new tab: 
[wpws url="https://example.com/markets" query="#prices table" basehref="1" a_target="_blank"]

Callbacks

WP WS Reborn 2026 supports two callback arguments:

  • callback_raw – Called before all parsing, filters, and link fixes. Receives the raw response (string or array). Good for low-level transforms, logging, or custom decoding.
  • callback – Called after all parsing, filters, remove_query/replace_query, basehref, and a_target. Receives the final processed string. Use for formatting, JSON/XML parsing, or last‑step cleanup.

Both callbacks must be the name of a callable PHP function that is available (e.g. in your theme’s functions.php or a custom plugin). The plugin validates and sanitizes data before and after the callback for security.

Allow-list (security): for safety, only allow-listed functions may run as callbacks. Any function whose name starts with wpws_ (the plugin’s built-in helpers and your own) is allowed automatically, plus a few harmless text helpers. To permit one of your own non-wpws_ functions, add it via the wpws_allowed_callbacks filter: 
add_filter( 'wpws_allowed_callbacks', function ( $list ) {
    $list[] = 'my_json_parser';
    return $list;
} );
Parameterised callbacks: pass arguments with name:arg1,arg2. The value(s) after the colon are passed to your function after the content. Example: callback="wpws_drop_columns:4" calls wpws_drop_columns($content, '4'). See Table filtering helpers.
Example – JSON response, extract one field via callback: 
[wpws url="https://api.ipify.org?format=json" basehref="0" callback="wpws_my_json_parser"]

In theme functions.php (the wpws_ prefix means it is allow-listed automatically):

function wpws_my_json_parser( $content ) {
    $obj = json_decode( trim( $content ) );
    return $obj ? $obj->ip : '';
}

Tip: for JSON, the built-in JSONPath query type (query="$.ip" query_type="jsonpath") does this with no callback.

Example – preprocess raw HTML via callback_raw: 
[wpws url="https://example.com" query=".content" callback_raw="wpws_my_raw_filter"]

In theme functions.php:

function wpws_my_raw_filter( $raw ) {
    // Example: strip tracking query parameters before parsing
    return preg_replace( '/utm_[^&]*/', '', $raw );
}

Table filtering helpers

When you scrape a table you often want only some of its columns or rows. These built-in helper functions take the table HTML and return a trimmed table. Use them via callback with the parameterised name:args syntax. Column/row numbers are 1-based, and specs support single numbers (4), lists (4_7_9) and ranges (5-8), e.g. 1-3_7.

  • wpws_drop_columns:SPEC – remove the listed columns, keep the rest (e.g. keep 6 of 10 by dropping 4).
  • wpws_keep_columns:SPEC – keep only the listed columns.
  • wpws_drop_rows:SPEC – remove the listed rows, keep the rest.
  • wpws_keep_rows:SPEC – keep only the listed rows.
Example – scrape a table but drop column 2 (keep the rest): 
[wpws url="https://www.w3schools.com/html/html_tables.asp" query="#customers" callback="wpws_drop_columns:2"]
Example – keep columns 1–3 and 7 only: 
[wpws url="https://example.com/report" query="table.data" callback="wpws_keep_columns:1-3_7"]

Other ready-made helpers (no arguments needed): wpws_keep_first_3_columns … wpws_keep_first_10_columns, wpws_keep_first_3_rows … wpws_keep_first_10_rows, combined ones like wpws_keep_4_cols_5_rows, and wpws_keep_mobile_table_columns (keeps columns 1, 2, 3, 4 and 10).

From PHP you can call them directly, e.g. echo wpws_drop_columns( $html, '2_5_8_9' ); or the low-level wpws_filter_table_advanced( $html, $columns_spec, $rows_spec ) / wpws_filter_table_exclude( $html, $columns_spec, $rows_spec ).

Note: column positions are counted per row. Tables that use colspan/rowspan (merged cells) may not line up — in that case prefer wpws_keep_columns with an explicit list.

Text helper: bold words

wpws_bold_words wraps whole-word, case-insensitive matches in <strong>. Pass the words with the parameterised syntax (comma-separated):

[wpws url="https://example.com/standings" query="table" callback="wpws_bold_words:Gorica,Dinamo"]

The shortcut wpws_bold_gorica bolds just “Gorica”.

Authentication

Send credentials with the request to scrape protected endpoints:

  • auth_type – none (default), basic, or bearer.
  • auth_user / auth_pass – username and password for basic auth (sent as an Authorization: Basic header).
  • auth_token – token for bearer auth (sent as Authorization: Bearer …).
[wpws url="https://api.example.com/data" query="$.value" query_type="jsonpath" auth_type="bearer" auth_token="YOUR_TOKEN"]
Security: credentials placed in a shortcode are stored in the post content. Prefer the block or template tag, restrict who can edit those posts, and use HTTPS endpoints. Credentials are never printed in the debug comment (they are masked).

Mobile emulation

Request the mobile version of a page by sending a mobile User-Agent and client hints:

  • mobile – 1 to enable, 0 to disable (default).
  • mobile_type – generic (default), android, iphone, or ipad.
[wpws url="https://example.com" query=".m-table" mobile="1" mobile_type="iphone"]

Mobile and desktop responses are cached separately.

AJAX lazy load & background refresh

  • ajax – 1 renders a placeholder immediately and loads the scraped content in the browser via AJAX after the page paints. Good for slow sources so they don’t block your page render.
  • background_refresh – 1 serves the cached copy instantly and, once the cache is ~90% expired, refreshes it in the background via WP-Cron (stale-while-revalidate). Visitors never wait for a refetch.
[wpws url="https://slow.example.com/feed" query=".headlines li" ajax="1"]
[wpws url="https://example.com/rates" query="#rates" cache="30" background_refresh="1"]
On network errors or temporary HTTP failures the plugin automatically falls back to the last good cached copy (up to 7 days), and uses ETag/Last-Modified conditional requests to avoid re-downloading unchanged pages.

Dynamic URLs

Placeholders in the URL are replaced using values from $_GET:

  • ___param___ – Replaced with $_GET['param'].
  • ___QUERY_STRING___ – Replaced with the full query string.
Example – stock symbol from query: 
[wpws url="https://example.com/quote?symbol=___symbol___" query=".price"]

Visit the page with ?symbol=AAPL to use Apple.

on_error handling

Controls what is shown when a request or parsing fails:

  • on_error="error_show" – Show the plugin error message (default).
  • on_error="error_hide" – Show nothing.
  • on_error="Your message" – Show that string instead.
[wpws url="https://example.com/stock/___symbol___" query=".quote" on_error="Stock data unavailable"]

Atom/RSS feed link shortcodes

Two extra shortcodes extract links of a given file type from any Atom/RSS feed — handy for image galleries from RSS or download lists from Atom.

wpws_atom_links

Regex-based: finds every http(s) URL ending in the given extension anywhere in the feed (matches href and url attributes, including media:content). No XML namespace headaches.

  • url – Required. Feed URL.
  • extension – File extension without dot (default jpg).
  • format – list (HTML <ul>, default) or plain (one URL per line).
  • cache – Minutes to cache (default 60).
[wpws_atom_links url="http://rss.cnn.com/rss/cnn_topstories.rss" extension="jpg"]

wpws_atom_zip_links

DOM-based alternative for proper Atom feeds: reads <link href>, <enclosure> and media:content elements. Same arguments; url is required and extension defaults to zip.

[wpws_atom_zip_links url="https://example.com/atom_feed.xml" extension="zip" format="plain"]

Gutenberg block

In the block editor, add the WP Web Scraper block (search “scraper”). Set the URL, query, query type, output, cache, authentication and background refresh in the block sidebar; a live preview renders in the editor. The block is server-side rendered, so output always reflects the current source on the front end.

Security & allow-listed callbacks

The plugin ships with several protections, configurable under Settings → WP WS Reborn 2026:

  • SSRF protection – blocks requests to localhost and private/internal IP ranges (incl. cloud metadata). Each redirect hop is re-validated, and hosts are checked across both IPv4 and IPv6 plus integer-IP encodings.
  • Domain whitelist / blacklist – restrict scraping to (or away from) specific domains, one per line.
  • Require HTTPS – reject plain http:// URLs.
  • HTML sanitisation – scraped output is run through wp_kses (post context) and <script> blocks are stripped.
  • Rate limiting – cap requests per domain per time window (default 20 / 60 s).
  • Allow-listed callbacks – only wpws_* and explicitly registered functions may run as callbacks (see Callbacks).
“Allow access to localhost / private IPs” exists for local development only — leaving it on in production exposes your server to SSRF. Keep it off unless you know you need it.

Examples

CSS table row with eq (Meteo.hr)

Use a more specific query so that eq selects one row instead of the whole table.

Shortcode

[wpws 
  url="https://meteo.hr/podaci.php?section=podaci_vrijeme&m=hrvatska1_n" 
  query=".fd-c-table--responsive tbody tr" 
  eq="3" 
  output="html"]

This selects the fourth table row (eq is 0‑based: 0 = first row, 3 = fourth row).

RSS / Atom feed, XPath, first 10 titles

Fetch the latest BBC News headlines from the RSS feed and show the first 10 item titles as a list.

Shortcode

[wpws url="https://feeds.bbci.co.uk/news/rss.xml" query="//item/title" glue="<br />" query_type="xpath" output="text" lt="10"]

Template Tag

<?php echo wpws_get_content(
    'https://feeds.bbci.co.uk/news/rss.xml',
    '//item/title',
    array(
        'query_type' => 'xpath',
        'glue'       => '<br />',
        'output'     => 'text',
        'lt'         => 10,
    )
); ?>

Output (example)

al-Baghdadi
Sixers
Happy Diwali
Southwest Airlines flight attendant
Shakur Stevenson
Syracuse football
Sylvia Plath
Ohio State football
Oklahoma football
Auburn vs LSU

JSON via JSONPath

Parse a JSON source and extract one field with the built-in JSONPath query type — no custom callback required.

Shortcode

[wpws url="https://api.ipify.org?format=json" query="$.ip" query_type="jsonpath" basehref="0"]

Template Tag

<?php echo wpws_get_content(
    'https://api.ipify.org?format=json',
    '$.ip',
    array(
        'query_type' => 'jsonpath',
        'basehref'   => 0,
    )
); ?>

Output (example)

50.87.248.113
Prefer JSONPath for JSON. If you still want a custom callback (e.g. my_json_parser), allow-list it first via the wpws_allowed_callbacks filter — see Callbacks.

remove_query and a_target

Fetch “Trending Now” text and remove bold tags, opening links in a new window.

Shortcode

[wpws url="https://www.yahoo.com/" query="ol.trendingnow_trend-list li" remove_query="b" a_target="_blank"]

Template Tag

<?php echo wpws_get_content(
    'https://www.yahoo.com/',
    'ol.trendingnow_trend-list li',
    array(
        'a_target'    => '_blank',
        'remove_query' => 'b',
    )
); ?>

basehref and a_target

Fetch an external table and open any links in a new tab.

Shortcode

[wpws url="https://www.w3schools.com/html/html_tables.asp" query="#customers" basehref="1" a_target="_blank"]

Template Tag

<?php echo wpws_get_content(
    'https://www.w3schools.com/html/html_tables.asp',
    '#customers',
    array(
        'basehref'  => 1,
        'a_target'  => '_blank',
    )
); ?>

Dynamic URL and on_error

Use a URL with a placeholder (e.g. ___symbol___) and show a custom message if the request fails.

Shortcode

[wpws url="https://example.com/quote?symbol=___symbol___"
      query=".price"
      on_error="Quote not available. Pass ?symbol= in the URL."]

Template Tag

<?php echo wpws_get_content(
    'https://example.com/quote?symbol=' . ( isset( $_GET['symbol'] ) ? esc_attr( $_GET['symbol'] ) : '' ),
    '.price',
    array(
        'on_error' => 'Quote not available. Pass ?symbol= in the URL.',
    )
); ?>

Combining gt and lt (range)

Select only a middle range of elements using gt and lt.

Shortcode

[wpws url="https://example.com/news" query="h2" gt="2" lt="8" output="text" glue=" | "]

Returns headlines at indices 3–7 only.

Feed links by extension (wpws_atom_links)

Extract only links that start with http:// or https:// and end with a given file extension from any Atom/RSS feed. Useful for image URLs in RSS (media:content) or download links in Atom feeds.

Shortcode

[wpws_atom_links url="http://rss.cnn.com/rss/cnn_topstories.rss" extension="jpg"]

Returns all image (.jpg) URLs from the CNN top stories RSS feed. Use format="plain" for one URL per line, or extension="zip" for .zip links (e.g. on Atom feeds).

Admin: Sandbox, Import, Help

  • Sandbox – Test URL, query, and arguments before using them in posts. Use “Test Scrap” or “Test Shortcode”. Results appear in the Output, Shortcode, Template Tag, and Debug tabs.
  • Import – Create posts from scraped content. Title, content, and tags can include shortcodes. Optional URL override, categories, status, author. “Post as shortcode” keeps content dynamic.
  • Help – In-plugin docs and examples.
  • Quick Help – Sidebar with shortcode/template syntax, query types, and common arguments.
Tip: Use Sandbox first to verify queries and copy the generated shortcode or template tag.

Requirements & resources

  • PHP 7.4+
  • WordPress 5.0+
  • Symfony CSS Selector (included). Caching uses WordPress Transients; a cache plugin (e.g. Redis, Memcached) improves performance.

Rate limiting: 20 requests per minute per domain by default (configurable under Settings → Rate Limiting).
